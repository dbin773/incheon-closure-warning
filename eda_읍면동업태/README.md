# EDA: 인천 분기×읍면동×업태 다음분기 폐업률

사업체×분기 LightGBM의 성능이 낮아(가게끼리 예측확률 차이가 거의 없음) 분석 단위를 **기준분기 × 읍면동 × 업태(음식점/카페)**로 바꾼 데이터의 탐색적 분석입니다.
데이터 파일(`인천_분기x읍면동x업태_다음분기폐업률.csv`, 3,642행 × 44열)은 저장소에 올리지 않았습니다.

## 실행
```bash
python eda_figures.py <데이터.csv> figures     # 그림 1~4
python eda_full.py    <데이터.csv> .           # 그림 5~7, tables/*.csv
```
집계 폐업률은 모두 `폐업수 합 ÷ 점포수 합`(점포수 가중)입니다.

## 핵심 결과
1. **소표본 잡음**: 점포 1~9개 칸은 90%가 폐업률 0, 100개 이상 칸은 3%만 0. 점포수 가중이 필요.
2. **4분기 급증**: 음식점 평소 2.2~2.5% → 4분기 2.9~3.9%.
3. **카페 분포 변화**: 카페 폐업률 학습 3.5% → 테스트(2026) 2.2%.
4. **읍면동_ 변수는 음식점 칸에서 읍면동업태_ 변수와 거의 같음** (Spearman 0.90~1.00), 카페 칸에선 0.42~0.96.
5. **강한 중복 쌍**: 영업점포수↔직전분기말점포수(0.999), 업태구분↔점포비중(-0.87), 평균↔중앙시설규모(0.83).
6. **타깃과 관련 큰 변수**(점포 30개 이상): 평균업력개월 -0.35, 읍면동업태_폐업률_4Q평균 +0.35.
7. **타깃 정의**: 다음분기_폐업수는 "현재 영업 중인 점포 중 다음 분기 폐업" 수라서, 다음 분기에 새로 열고 같은 분기에 닫은 가게는 빠짐 (전체 약 9%).
