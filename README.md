# 인천 음식점·카페 폐업위기 조기경보 모델

인천시 일반음식점·휴게음식점 인허가 자료와 주민등록인구 통계로 만든 **사업체×분기 패널**을 이용해, 기준분기 말 영업 중인 사업체가 **다음 분기에 폐업할 확률**을 LightGBM으로 예측하고, SHAP으로 변수 중요도를 해석한 뒤 성능을 평가합니다.

## 데이터
- 파일: `[전처리10_최종]인천_사업체-분기_패널_군구인구_YoY보완 (2).zip` (저장소에는 포함하지 않음)
- 출처: 행정안전부 지방행정 인허가 데이터(일반음식점·휴게음식점), 행정안전부 주민등록 인구 및 세대현황(월간)
- 규모: 531,398행(사업체 50,334개 × 2023Q1~2026Q2, 14개 분기)
- 타깃: `다음분기_폐업여부` (폐업 14,141건, 2.66%, 폐업:비폐업 ≈ 1:37)

## 예측인자(26개)
| 묶음 | 변수 |
|---|---|
| 업태 | 업태구분_2진수(0=음식점, 1=카페), 읍면동업태_점포비중 |
| 사업체 특성 | 업력개월, 시설규모_log, 다중이용업소여부(Y/N→1/0) |
| 시간 | 분기번호, 시간순번 |
| 군구 인구·수요 | 군구_총인구, 군구_인구증감률_QoQ, 군구_인구증감률_YoY, 군구_인구천명당_전체점포수, 군구_인구천명당_동일업태점포수 |
| 군구×업태 상권 | 군구업태_개업률, 군구업태_폐업률, 군구업태_폐업률_lag1, 군구업태_폐업률_lag4, 군구업태_폐업률_4Q평균, 군구업태_공급수요격차 |
| 읍면동 상권 | 읍면동_영업점포수, 읍면동_개업률, 읍면동_폐업률, 읍면동_점포수증감률, 읍면동_폐업률_lag1, 읍면동_폐업률_lag4, 읍면동_폐업률_4Q평균, 읍면동업태_영업점포수 |

관리번호·기준분기·군구명_개편후·업태구분명은 모델에 넣지 않고 분할·집계·신뢰구간 계산에만 사용합니다.

## 방법
- **시간순 분할**: 학습 2023Q1~2024Q4 / 검증 2025Q1~Q4 / 테스트 2026Q1~Q2 (무작위 분할 시 같은 사업체·미래 정보가 섞여 성능이 부풀려짐)
- **모델**: LightGBM(이진분류), 검증 PR-AUC 기준 조기 종료, 클래스 가중치 미적용
- **확률 보정**: 검증 데이터로 Isotonic 보정(군구별 확률 합산 = 예상 폐업 수)
- **경보 임계값**: 검증 데이터에서 F2 점수 최대값
- **성능평가**: PR-AUC(주 지표), ROC-AUC, 상위 5·10% 재현율·정밀도·Lift, Brier, Log loss, 사업체 단위 부트스트랩 95% CI(1,000회), 업태·군구별 성능, 군구별 예상 vs 실제 폐업률, 확장 창 시계열 교차검증(6개 폴드)
- **해석**: TreeSHAP, 평균 |SHAP| 기반 변수·변수군 중요도, 요약도·의존도

## 실행 방법
1. Colab에서 `LightGBM_SHAP_성능평가.ipynb`를 엽니다(GitHub 링크로 바로 열거나 파일 업로드).
2. 데이터 zip을 노트북과 같은 위치에 올립니다(압축 해제 불필요).
3. **런타임 → 모두 실행**. 결과는 `results/`, `figures/`에 저장됩니다. 시드 42 고정으로 같은 결과가 재현됩니다(라이브러리 버전에 따라 소수점 셋째 자리 정도 차이 가능).

## 주요 결과(테스트 2026Q1~Q2)
| 지표 | 값 | 95% CI |
|---|---|---|
| PR-AUC | 0.051 (무작위 0.023의 약 2.2배) | 0.044~0.058 |
| ROC-AUC | 0.634 | 0.620~0.647 |
| 상위 10% 재현율 | 0.218 | 0.197~0.235 |
| Brier | 0.0221 | 0.0210~0.0231 |

- 시계열 교차검증(2024Q3~2025Q4): PR-AUC 0.059 ± 0.017, ROC-AUC 0.646 ± 0.007. 연말 폐업이 몰리는 3분기 폴드에서도 유지됨.
- 업태별: 음식점 PR-AUC 0.055(무작위의 2.4배), 카페 0.027(1.2배). 카페 예측력은 약함.
- 군구 단위 집계: 예상 폐업률과 실제 폐업률의 순위상관 2026Q1 0.92, 2026Q2 0.70.
- SHAP 변수군 중요도: 사업체 특성 60%, 읍면동 상권 15%, 군구 인구·수요 10%, 군구×업태 상권 8%, 시간 4%, 업태 3%.
- 개별 변수 상위: 업력개월(짧을수록 위험↑), 시설규모_log(작을수록 위험↑), 읍면동_폐업률_4Q평균(높을수록 위험↑).

## 해석 시 유의점
- `업태구분_2진수`와 `읍면동업태_점포비중`은 상관이 0.99라, 업태 효과가 거의 `읍면동업태_점포비중` 쪽에 잡힙니다. 업태 영향은 두 변수를 묶은 "업태" 변수군 값으로 보세요.
- 분석 결과는 예측적 연관성이며 폐업의 원인으로 해석하지 않습니다. 인허가 자료에는 매출·임대료 정보가 없어 개별 사업체 예측력에는 한계가 있습니다.
- Baseline(로지스틱 회귀)은 별도로 수행합니다. 비교할 때는 같은 테스트 기간(2026Q1~Q2)과 같은 지표(PR-AUC, ROC-AUC, Recall@10%)를 사용하면 됩니다.
